# FUNCIONA de fato é a Content-Security-Policy via <meta http-equiv> no
# <head> de index.html/admin.html — que não cobre X-Frame-Options (sem
# equivalente via <meta>; clickjacking fica sem mitigação até migrar).
# Ver README.md, seção "Hospedagem e deploy".
